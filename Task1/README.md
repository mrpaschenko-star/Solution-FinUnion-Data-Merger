# Task1 — сущности, качество и хранилища

Логическая модель содержит 15 сущностей. Исходный список сохранён и уточнён: транзакция отделена от бухгалтерской проводки и платежного поручения; добавлены соответствия идентификаторов, роли сторон договора, согласия и валютный курс. Это позволяет объединять аналитику, не теряя банковский смысл данных.
